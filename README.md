# Student Performance Data Visualization

An exploratory data analysis and visualization project using Python to investigate student academic performance, study habits and class-wise trends.

### Visualizations
- Line plot – Monthly test average trends.
- Bar chart – Individual student marks.
- Histogram – Distribution of final marks.
- Scatter plot – Study hours vs marks.
- Pie chart – Preferred programming languages.
- Count plot – Student distribution by class.
- Box plot – Class-wise marks comparison.
- Heatmap – Correlation between academic factors.
- Comparative plots – Performance across classes and programming language preferences.

### Technologies
- Python 3
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

### Concepts Practised
Data visualization, exploratory data analysis, aggregation, grouping, correlation analysis, categorical analysis and statistical plotting.

### Project Structure
- `Harisanker_Matplotlib_Seaborn_Practice.ipynb` – Visualization exercises, implementations and observations.

### Run
Open the notebook using Jupyter Notebook, JupyterLab or Google Colab and execute the cells sequentially.
